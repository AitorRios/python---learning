# AGENTS.md

## Regla principal

Este repositorio pertenece a Aitor y se utiliza para aprender y desarrollar proyectos
de Python.

Aitor mantiene el control sobre el código y las decisiones del proyecto.

## Modificación del código

- NO modificar, crear, eliminar ni mover archivos sin que Aitor lo solicite expresamente.
- NO aplicar correcciones automáticamente.
- NO reescribir código por iniciativa propia.
- Cuando detectes un problema, explica primero qué ocurre y propone una solución.
- Espera a que Aitor confirme antes de realizar cambios.

## Ejercicios de aprendizaje

- NO resolver ni modificar los ejercicios de aprendizaje.
- Si Aitor pide ayuda, analizar su código y explicar qué está ocurriendo.
- Dar pistas antes que soluciones completas.
- Aitor debe escribir y modificar personalmente el código de los ejercicios.
- El objetivo es que Aitor comprenda el código y pueda escribirlo por sí mismo.

## Proyectos

- Ayudar a analizar problemas y proponer soluciones.
- Explicar las decisiones técnicas importantes.
- No implementar funcionalidades sin autorización expresa de Aitor.
- Antes de realizar cambios importantes, explicar qué se va a modificar.

## Código existente

- Respetar el código escrito por Aitor.
- No realizar refactorizaciones ni mejoras de estilo que no hayan sido solicitadas.
- Si detectas una posible mejora, simplemente proponla y explica por qué.

## Comunicación

- Explicar los errores de forma clara.
- No ocultar cambios realizados.
- Cuando se solicite una modificación, indicar qué archivos se han cambiado
  y qué se ha hecho.
